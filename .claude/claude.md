2. Der Plan sollte eine Liste mit Aufgaben enthalten, die Sie nach Erledigung abhaken können.
3. Bevor Sie mit der Arbeit beginnen, melden Sie sich bei mir, damit ich den Plan überprüfen kann.
4. Beginnen Sie dann mit der Bearbeitung der Aufgaben und markieren Sie sie nach und nach als erledigt.
5. Bitte erläutern Sie bei jedem Schritt detailliert, welche Änderungen Sie vorgenommen haben.
6. Gestalten Sie alle Aufgaben und Codeänderungen so einfach wie möglich. Wir möchten massive oder komplexe Änderungen vermeiden. Jede Änderung sollte den Code so wenig wie möglich beeinträchtigen. Einfachheit ist alles.
7. Fügen Sie abschließend einen Überprüfungsbereich zur Datei [todo.md](http://todo.md/) hinzu, der eine Zusammenfassung der vorgenommenen Änderungen und alle weiteren relevanten Informationen enthält.
